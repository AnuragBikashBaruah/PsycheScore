## Instructions

1. Download the dataset from the link above
2. Place the files inside this `data/` directory
3. Maintain the following structure (if applicable):

```
data/
├── raw/
```

* `raw/` → original dataset files
* `processed/` → cleaned or transformed data used for training

## Notes

* Ensure the dataset format matches what is expected by the training scripts in the `notebooks/` folder
* Update file paths in the code if your dataset structure differs
